# بازی کیان‌پوری + ربات تلگرام مدیریت

## راه‌اندازی روی Railway (۵ مرحله)

1. پروژه را روی Railway دیپلوی کن (GitHub یا آپلود).
2. در تب **Variables** این‌ها را اضافه کن:
   - `BOT_TOKEN` = توکن ربات از BotFather  ← **حتماً اینجا، نه داخل کد**
   - `ADMIN_IDS` = `1601379026`  (اختیاری، پیش‌فرض همین است)
   - `DATA_DIR` = `/data`
3. در تب **Settings → Volumes** یک Volume بساز و Mount Path را `/data` بگذار
   (تا با هر دیپلوی دیتا پاک نشود). حتی بدون Volume، ربات هر ۲۴ ساعت بکاپ JSON برایت می‌فرستد.
4. در **Settings → Networking** دامنه عمومی (Generate Domain) بساز.
5. داخل تلگرام ربات را باز کن و `/start` بزن.

## امکانات ربات
- اعلان لحظه‌ای هر ورود: کشور، شهر، IP، ISP، مدل دستگاه (تقریبی)، سیستم‌عامل، مرورگر، صفحه، RAM، باتری، شبکه، زبان، ساعت ورود
- پنل با بخش‌ها: آمار، آنلاین‌ها، بازدیدکننده‌ها، رکوردها، کشورها، دستگاه‌ها، جستجو، بن IP/کشور،
  کنترل سایت (حالت نگهداری، سرعت بازی، سپر اولیه، رفرش اجباری)، بنر و پیام مستقیم به کاربر،
  تنظیم اعلان‌ها، خروجی CSV و بکاپ JSON، وضعیت سرور
- دستورها: `/panel /stats /online /find /ban /unban /say /maintenance /backup /restore`
- بازگردانی بکاپ: فایل JSON را برای ربات بفرست با کپشن `/restore`

## نکته
جمع‌آوری IP و اطلاعات دستگاه بازدیدکننده‌ها حریم خصوصی دارد؛ بهتر است یک جمله در سایت بنویسی.
